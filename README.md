# ♟️ CHECKMATE.GG

**Быстрая игра в шахматы с AI-анализом и красивым интерфейсом.**

## Что это?

CHECKMATE.GG — это full-stack веб-приложение для игры в шахматы с встроенным анализом партий и тренировкой. Собранно на **Next.js**, **Express**, **Lichess API** и **Groq AI**.

## Для кого?

- 🎮 **Шахматисты** — быстрые партии против ИИ (уровни 1-8)
- 📊 **Тренирующиеся** — анализ игры от personas (Tal, Karpov, Carlsen)
- 🏆 **Конкурирующие** — лидерборды и сохранение игр
- 💻 **Разработчики** — open-source проект для расширения

## Почему это ценно?

✅ **Играй в любом браузере** — без установки, без регистрации  
✅ **AI ходит реально** — 75-depth Lichess Cloud анализ  
✅ **Анализ партий** — AI coach в стиле Carlsen, Karpov или Tal  
✅ **Сохранение игр** — все партии в localStorage или БД  
✅ **Красивый интерфейс** — neon-red theme, responsive дизайн  
✅ **Полный stack** — фронтенд, бэкенд, auth, сокеты — все работает  

## Быстрый старт

```bash
# Backend (Express + Socket.io)
cd backend
npm install
npm start

# Frontend (Next.js)
cd frontend
npm install
npm run dev
```

Открой http://localhost:3000 → **Play vs AI** → Choose level → Enjoy! 🎉
