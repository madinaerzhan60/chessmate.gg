# ♟️ CHECKMATE.GG

**Быстрая игра в шахматы с AI-анализом и красивым интерфейсом.**

## Что это?

CHECKMATE.GG — это full-stack веб-приложение для игры в шахматы с встроенным анализом партий и тренировкой. Собранно на **Next.js**, **Express**, **Lichess API** и **Groq AI**.

## Для кого?

- 🎮 **Шахматисты** — быстрые партии против ИИ (уровни 1-8)
- 📊 **Тренирующиеся** — анализ игры от personas (Tal, Karpov, Carlsen)
- 🏆 **Конкурирующие** — лидерборды и сохранение игр
- 💻 **Разработчики** — open-source проект для расширения

## Почему это ценно?

✅ **Играй в любом браузере** — без установки, без регистрации  
✅ **AI ходит реально** — 75-depth Lichess Cloud анализ  
✅ **Анализ партий** — AI coach в стиле Carlsen, Karpov или Tal  
✅ **Сохранение игр** — все партии в localStorage или БД  
✅ **Красивый интерфейс** — neon-red theme, responsive дизайн  

## Мобильная версия

CHECKMATE.GG нормально работает на телефоне и планшете. Интерфейс автоматически подстраивается под ширину экрана, а шахматная доска уменьшается до удобного размера, чтобы не вылезать за границы экрана.

Что уже есть в mobile-версии:

- 📱 Адаптивная доска в режимах `Play`, `Puzzles`, `Analyze` и `Profile`
- 👆 Ход по нажатию на клетку без обязательного drag-and-drop
- 🧭 Упрощенная навигация и карточки, которые перестраиваются в одну колонку
- 🔗 Invite links, saved games и анализ партий доступны с мобильного браузера

Как играть с телефона:

1. Откройте страницу `Play` или `Puzzles`
2. Нажмите на свою фигуру, затем на клетку назначения
3. Если играете онлайн, дождитесь, пока роль определится и второй игрок подключится
4. Для удобства переверните экран в горизонтальный режим, если нужна большая доска

Ограничения:

- На очень маленьких экранах некоторые панели могут становиться ниже, чтобы сохранить читаемость
- Drag-and-drop работает не везде одинаково, поэтому основной способ хода на мобильном — click-to-move
- Для лучшего опыта используйте современный mobile браузер с включенными cookies и localStorage

## Быстрый старт

```bash
# Backend (Express + Socket.io)
cd backend
npm install
npm start

# Frontend (Next.js)
cd frontend
npm install
npm run dev
```

Открой http://localhost:3000 → **Play vs AI** → Choose level → Enjoy! 🎉
